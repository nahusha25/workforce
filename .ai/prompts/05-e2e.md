# Prompt 05 — E2E Test Creation

Use this prompt to create Playwright E2E tests for a user journey.

## Instructions

Follow `.ai/workflows/e2e-testing.md`.

### 1. Identify the Journey
- Journey name:
- Phase:
- Actors involved:
- Requirement reference:

### 2. Define Preconditions
- Test data required (employees, sites, etc.)
- Authentication state
- Application state

### 3. Write Test Steps

```typescript
test.describe('<Journey Name>', () => {
  test.beforeAll(async () => {
    // Seed test data via API
  });

  test.afterAll(async () => {
    // Clean up test data
  });

  test('happy path — <description>', async ({ page }) => {
    // Step 1: Navigate
    // Step 2: Interact
    // Step 3: Assert
  });

  test('validation failure — <description>', async ({ page }) => {
    // Test invalid input handling
  });

  test('permission failure — <description>', async ({ page }) => {
    // Test as wrong role
  });
});
```

### 4. Selector Strategy
- Use `data-testid` attributes
- Use ARIA roles and labels
- Add missing `data-testid` to components as needed

### 5. Assertions
- Verify visible text/content
- Verify navigation
- Verify API responses (intercept if needed)
- Verify data persistence (query API after action)

### 6. Run and Verify
```bash
npx playwright test <test-file> --headed
```
